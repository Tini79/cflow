# Log API Endpoints

This page provides an overview of the available API endpoints for managing every Log on Cakrahub Channel Manager.

## 1. Get Internal Booking Log List

Used to retrieve logs showing whether each booking was successfully sent to the PMS or failed.

**Endpoint:** `GET /GetInternalBookingList/{hotel_code}`

**Parameters:**
- `hotel_code`: Hotel code

**Example Request:**

```javascript
const axios = require('axios');

let config = {
  method: 'get',
  maxBodyLength: Infinity,
  url: 'https://cm.cakrasoft.net/cm/api/v2/GetInternalBookingList/CKR'
};

axios.request(config)
.then((response) => {
  console.log('Log list retrieved successfully');
})
.catch((error) => {
  console.log(error);
});
```

**Example Response:**

#### Response Field Details
**Result**: An array containing log records returned by the API.
  - `amount`: The total booking amount charged for the reservation.
  - `booking_date`: The timestamp when the booking was created by the OTA or source system.
  - `booking_id`: The unique UUID assigned to the booking record in the system.
  - `booking_status`: The OTA or internal booking status code (e.g., 0 = new).
  - `booking_unique_id`: A unique tracking ID for the booking, usually generated by the OTA.
  - `check_in`: The scheduled check-in date for the guest.
  - `check_out`: The scheduled check-out date for the guest.
  - `created_at`: Timestamp when the booking record was created in the system.
  - `created_by`: Indicates who created the booking record (system/user).
  - `currency_code`: The currency used for the booking amount.
  - `hotel_code`: The identifier of the hotel receiving the booking.
  - `id`: The internal database ID for the booking.
  - `ota_code`: The OTA or booking source code (e.g., TRK = Tiket.com).
  - `ota_id`: The booking reference ID from the OTA system.
  - `rate_plan_code`: The rate plan associated with the reservation.
  - `revision_id`: The revision UUID used to track changes to the booking.
  - `room_booking_id`: The UUID representing the room segment within the booking.
  - `room_type_code`: The internal room type code for the booked room.
  - `status`: The internal processing status (e.g., S = success).
  - `time_add`: Timestamp when the booking first entered the system.
  - `time_confirm`: Timestamp when the booking was confirmed or acknowledged.
  - `time_notif`: Timestamp when the notification was processed.
  - `updated_at`: Timestamp when the booking record was last updated.
  - `updated_by`: Indicates who last updated the booking record.

**Endpoint:** `GET /GetLogEmailList/{hotel_code}`

**Parameters:**
- `hotel_code`: Hotel code

**Example Request:**

```javascript
const axios = require('axios');

let config = {

  maxBodyLength: Infinity,

axios.request(config)
.then((response) => {
  console.log('Log retrieved successfully');
})

```

**Example Response:**

```json

  "StatusCode": 0,

  "Result": [
```

#### Response Field Details
**Result**: An object containing hotel/log record returned by the API.

## 4. Update Internal Booking Status API

Used to update the internal booking status.

**Endpoint:** `PUT /UpdateInternalBookingStatus`

**Request Body:**

```json
{
  "booking_id": "8f2b5671-9ad1-4c3f-b891-d1dfb8da0012",
  "room_booking_id": "f991aa22-5513-4ffd-915a-2d37f9b9d9d4",
}
```

#### Request Body Field Details
  - `booking_id`: The unique UUID assigned to the booking record in the system.
  - `room_booking_id`: The UUID representing the room segment within the booking.
---

**Example Request:**

```javascript
const axios = require('axios');

let data = JSON.stringify({
  "booking_id": "8f2b5671-9ad1-4c3f-b891-d1dfb8da0012",
  "room_booking_id": "f991aa22-5513-4ffd-915a-2d37f9b9d9d4",
});

let config = {
  method: 'put',
  maxBodyLength: Infinity,
  url: 'https://cm.cakrasoft.net/cm/api/v2/UpdateInternalBookingStatus',
  headers: {
    'Content-Type': 'application/json',
    'token': 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleHAiOjE3NjIyNDE1NDQsInVzZXIiOiJDTSBURUFNIn0.W-JJ1uXJ9hvNyZVYZVoRLmuZoJ_zS4YEtx-VZwJEtm0'
  },
  data : data
};

axios.request(config)
.then((response) => {
  console.log(JSON.stringify(response.data));
})
.catch((error) => {
  console.log(error);
});
```

---

**Example Response:**

```json
{
  "StatusCode": 0,
  "Message": "Success",
  "Result": null
}
```

## 5. Resend Email Log API

Used to resend email notifications that previously failed to be delivered to the registered property email address.

**Endpoint:** `POST /InsertInternalRatePlan`

**Request Body:**

```json
{
  "id": 45,
}
```

#### Request Body Field Details
- `id`: The unique identifier of the log or record that will be used for resending the failed email.
---

**Example Request:**

```javascript
const axios = require('axios');

let data = JSON.stringify({
  "id": 45,
});

let config = {
  method: 'post',
  maxBodyLength: Infinity,
  url: 'https://cm.cakrasoft.net/cm/api/v2/InsertInternalRatePlan',
  headers: {
    'Content-Type': 'application/json',
    'token': 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJleHAiOjE3NjIyNDE1NDQsInVzZXIiOiJDTSBURUFNIn0.W-JJ1uXJ9hvNyZVYZVoRLmuZoJ_zS4YEtx-VZwJEtm0'
  },
  data : data
};

axios.request(config)
.then((response) => {
  console.log(JSON.stringify(response.data));
})
.catch((error) => {
  console.log(error);
});
```

---

**Example Response:**

```json
{
  "StatusCode": 0,
```
